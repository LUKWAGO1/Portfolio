# Paul Lukwago — Developer Portfolio

A responsive dark-theme React portfolio built with Vite.

## Run locally

1. Install Node.js (LTS).
2. Extract this project.
3. Open a terminal in the project folder and run:

```bash
npm install
npm run dev
```

Open the local URL printed by Vite.

## Build for deployment

```bash
npm run build
npm run preview
```

The production site is generated in `dist/`. You can deploy the project to Netlify or Vercel.

## Personal details to update

- Add your preferred email address in `src/main.jsx` (the contact section currently displays a reminder instead of inventing an address).
- Replace each project link in the `projects` array with the direct repository URL.
- Confirm the Pivotal Software employment details and performance figures before publishing.
- Add any additional education details, certificates, profile photo, or project screenshots you want to feature.

## Tech

React, Vite, CSS, Lucide React.
